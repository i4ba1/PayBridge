# T07 Payment Admission Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `requestPayment` durably and idempotently admits one payment per invoice, never calls the provider, and `payment(id)` reads it back with merchant isolation.

**Architecture:** `AdmitPayment` (pure Java, `application`) orchestrates validation, replay lookup, gates, method resolution and up to 3 retries. The `AdmissionStore` port is implemented by `MysqlAdmissionStore`, which runs the exact DMR 6.1 SQL through `JdbcTemplate` inside one `TransactionTemplate` (statement order is the lock order). `core-app` adds the GraphQL fetcher, query limits and a startup consistency check. V003 and V004 ship in full.

**Tech Stack:** Java 25, Spring Boot 3.5.16, DGS 10.6.0, JdbcTemplate, MySQL 8.4 (Testcontainers), JUnit 5, AssertJ, Gradle 9.8.1 with dependency locking.

**Spec:** `docs/superpowers/specs/2026-10-18-t07-admission-design.md`. Source SQL: DMR sections 2 and 6.1 (`D:\backend-development\PayBridge_Data_and_Messaging_Reference_v1.docx`, V003, V004, "Recovery check queries", "Admission").

- Never leave the shell cwd inside a `build/` directory. Use the Write tool for long files (long Bash heredocs fail in Git Bash).
- Secrets: never print or commit values.

## Review Focus

Failure modes the spec implies but a literal reading of its test table does not pin. Each has a named test in the task that owns the code.

1. **Key case and format.** `A1B2...` uppercase UUIDs must replay the lowercase request (CHAR(36) `ascii_bin` compares exactly), and non-canonical UUIDs (`1-1-1-1-1`, no dashes, spaces) are `VALIDATION_ERROR`. Tests: `RequestPaymentCommandTest`, `AdmissionReplayIT.uppercaseKeyReplaysTheLowercaseRequest`.
2. **Same key in two merchants.** Two requests, never a replay across merchants. Test: `AdmissionReplayIT.sameKeyInAnotherMerchantIsANewRequest`.
3. **Hostile method tokens.** Empty, 129 characters, whitespace, non-ASCII, SQL metacharacters: `VALIDATION_ERROR`, no rows. Tests: `RequestPaymentCommandTest`, `InvoiceValidationIT`.
4. **Lock timeout side effects.** A held invoice lock yields `TEMPORARILY_UNAVAILABLE`, leaves no reservation, the same key works afterwards, and the 3 s session timeout does not leak to the next user of the pooled connection. Test: `LockWaitTimeoutIT`.
5. **Oversized or amplified GraphQL documents.** Over 8 KiB is HTTP 413 before parsing; 50 aliased list fields exceed complexity 300 and never reach a resolver. Tests: `GraphQlLimitsIT`, `GraphQlLimitsTest`.

## Spec refinements made by this plan (the spec is updated in Task 9)

- `PaymentAdmission.Rejected` carries `List<FieldProblem> fieldProblems` (the GraphQL `OperationProblem` already has that field) in addition to `code` and `retryAfterSeconds`.
- `AdmissionGate.check(merchantId)` returns `Optional<Closed>` instead of throwing `GateClosed`.
- `AdmissionStore.admit` result variants: `Created`, `Duplicate(Replay)`, `InvoiceNotFound`, `NotEligible`, `Transient` (the spec called the second one `Replay`, which collides with the `findReplay` record).
- The session lock-wait timeout is set as the first statement inside the Spring transaction and restored in `beforeCompletion`, not before `START TRANSACTION`. Same effect, and the pooled connection is left clean.
- Health: ConsistencyCheck is a port (`application.port.ConsistencyCheck`) with a MySQL adapter, so `core-app` still contains no SQL.
- Document size over 8 KiB is HTTP 413 from a `WebGraphQlInterceptor` with highest precedence; depth and complexity are graphql-java instrumentations (HTTP 200 with an `errors` entry).

```java
package com.paybridge.application.payment;

import com.paybridge.application.payment.PaymentAdmission.FieldProblem;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.ArrayList;
import java.util.HexFormat;
import java.util.List;
import java.util.Locale;
import java.util.regex.Pattern;

/** A validated, normalized requestPayment input. UUIDs are canonical lower case so one key has one spelling. */
public record RequestPaymentCommand(String invoiceId, String methodToken, String idempotencyKey) {
    public static final String OPERATION = "REQUEST_PAYMENT";
    private static final Pattern UUID_FORM =
            Pattern.compile("[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}");
    private static final Pattern TOKEN_FORM = Pattern.compile("[A-Za-z0-9_.-]+");

    public sealed interface Parse {
        record Valid(RequestPaymentCommand command) implements Parse {}

        record Invalid(List<FieldProblem> problems) implements Parse {}
    }

    public static Parse parse(String invoiceId, String methodToken, String idempotencyKey, int tokenMaxLength) {
        var problems = new ArrayList<FieldProblem>();
        if (!isUuid(invoiceId)) {
            problems.add(new FieldProblem("invoiceId", "INVALID", "Must be a UUID."));
        }
        if (methodToken == null || methodToken.isEmpty() || methodToken.length() > tokenMaxLength
                || !TOKEN_FORM.matcher(methodToken).matches()) {
            problems.add(new FieldProblem("methodToken", "INVALID", "Is not an accepted token."));
        }
        if (!isUuid(idempotencyKey)) {
            problems.add(new FieldProblem("idempotencyKey", "INVALID", "Must be a UUID."));
        }
        if (!problems.isEmpty()) {
            return new Parse.Invalid(List.copyOf(problems));
        }
        return new Parse.Valid(new RequestPaymentCommand(invoiceId.toLowerCase(Locale.ROOT), methodToken,
                idempotencyKey.toLowerCase(Locale.ROOT)));
    }

    private static boolean isUuid(String value) {
        return value != null && UUID_FORM.matcher(value).matches();
    }

    /** SHA-256 over "REQUEST_PAYMENT", invoice id and method token, separated by a newline, as lower case hex (DMR 6.1). */
    public String requestHash() {
        try {
            byte[] digest = MessageDigest.getInstance("SHA-256")
                    .digest((OPERATION + "\n" + invoiceId + "\n" + methodToken).getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(digest);
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException(e);
        }
    }
}
```

```java
package com.paybridge.application.payment;

import com.paybridge.application.payment.PaymentAdmission.Accepted;
import com.paybridge.application.payment.PaymentAdmission.Code;
import com.paybridge.application.payment.PaymentAdmission.FieldProblem;
import com.paybridge.application.payment.PaymentAdmission.Rejected;
import com.paybridge.application.payment.RequestPaymentCommand.Parse;
import com.paybridge.application.port.AdmissionGate;
import com.paybridge.application.port.AdmissionStore;
import com.paybridge.application.port.AdmissionStore.AdmissionRequest;
import com.paybridge.application.port.AdmissionStore.AdmissionResult;
import com.paybridge.application.port.AdmissionStore.Replay;
import com.paybridge.application.port.ScenarioRunResolver;
import com.paybridge.application.port.SystemFlags;
import java.util.List;
import java.util.Optional;
import java.util.concurrent.ThreadLocalRandom;
import java.util.function.LongConsumer;
import java.util.function.Supplier;

/**
 * Payment admission (DMR 6.1, FR-007 to FR-015). Order: validate, replay lookup, gates, method, one writer transaction.
 * The provider is never called here. A replay is answered before any gate, so a retry of an accepted request still gets
 * its answer while admission is closed.
 */
public final class AdmitPayment {

    public record Settings(boolean enabled, int methodTokenMaxLength, int lockWaitTimeoutSeconds, int maxAttempts,
                           long jitterMaxMillis, int retryAfterSeconds) {}

    private final AdmissionStore store;
    private final AdmissionGate gate;
    private final SystemFlags flags;
    private final ScenarioRunResolver runs;
    private final Settings settings;
    private final LongConsumer sleeper;
    private final Supplier<String> ids;

    public AdmitPayment(AdmissionStore store, AdmissionGate gate, SystemFlags flags, ScenarioRunResolver runs,
                        Settings settings, LongConsumer sleeper, Supplier<String> ids) {
        this.store = store;
        this.gate = gate;
        this.flags = flags;
        this.runs = runs;
        this.settings = settings;
        this.sleeper = sleeper;
        this.ids = ids;
    }

    public PaymentAdmission admit(AdmissionActor actor, String invoiceId, String methodToken, String idempotencyKey) {
        Parse parsed = RequestPaymentCommand.parse(invoiceId, methodToken, idempotencyKey, settings.methodTokenMaxLength());
        if (parsed instanceof Parse.Invalid invalid) {
            return new Rejected(Code.VALIDATION_ERROR, null, invalid.problems());
        }
        RequestPaymentCommand command = ((Parse.Valid) parsed).command();
        String hash = command.requestHash();

        Optional<Replay> replay = store.findReplay(actor.merchantId(), command.idempotencyKey());
        if (replay.isPresent()) {
            return answerFor(replay.get(), hash);
        }

        Rejected closed = closedGate(actor.merchantId());
        if (closed != null) {
            return closed;
        }

        var method = store.resolveMethod(actor.merchantId(), command.methodToken());
        if (method.isEmpty()) {
            return new Rejected(Code.VALIDATION_ERROR, null,
                    List.of(new FieldProblem("methodToken", "INVALID", "Is not an accepted token.")));
        }

        String paymentId = ids.get();
        var request = new AdmissionRequest(paymentId, ids.get(), actor.merchantId(), actor.userId(), command.invoiceId(),
                command.idempotencyKey(), hash, method.get().methodCode(), command.methodToken(),
                runs.runFor(actor.merchantId()), actor.correlationId(), settings.lockWaitTimeoutSeconds());

        for (int attempt = 1; attempt <= settings.maxAttempts(); attempt++) {
            AdmissionResult result = store.admit(request);
            if (result instanceof AdmissionResult.Created) {
                return new Accepted(paymentId, "REQUESTED", 1, false);
            }
            if (result instanceof AdmissionResult.Duplicate duplicate) {
                return answerFor(duplicate.existing(), hash);
            }
            if (result instanceof AdmissionResult.InvoiceNotFound) {
                return Rejected.of(Code.NOT_FOUND);
            }
            if (result instanceof AdmissionResult.NotEligible) {
                return Rejected.of(Code.INVOICE_NOT_ELIGIBLE);
            }
            if (attempt < settings.maxAttempts()) {
                sleeper.accept(ThreadLocalRandom.current().nextLong(1, settings.jitterMaxMillis() + 1));
            }
        }
        return Rejected.of(Code.TEMPORARILY_UNAVAILABLE, settings.retryAfterSeconds());
    }

    private PaymentAdmission answerFor(Replay replay, String hash) {
        if (replay.requestHash().equals(hash)) {
            return new Accepted(replay.paymentId(), replay.status(), replay.aggregateVersion(), true);
        }
        return Rejected.of(Code.IDEMPOTENCY_CONFLICT);
    }

    /** Static switch, then maintenance flag, then capacity flag, then the quota gate. Returns null when all are open. */
    private Rejected closedGate(String merchantId) {
        if (!settings.enabled() || flags.maintenanceOn() || flags.capacityClosed()) {
            return Rejected.of(Code.TEMPORARILY_UNAVAILABLE, settings.retryAfterSeconds());
        }
        return gate.check(merchantId).map(c -> Rejected.of(c.code(), c.retryAfterSeconds())).orElse(null);
    }
}
```
Careful: the gate-order test expects the maintenance read to short-circuit the capacity read. `||` does that, and `!settings.enabled()` short-circuits both flag reads. Good.

```java
package com.paybridge.it.admission;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import com.paybridge.application.payment.PaymentAdmission.Accepted;
import java.util.List;
import org.junit.jupiter.api.Test;
import org.springframework.dao.DataAccessException;

/**
 * FR-012: any failed statement rolls back everything, including the reservation. Failures are forced with database
 * triggers created by root, so the production code carries no test hook.
 */
class AtomicAdmissionRollbackIT extends AdmissionIT {

    private record Sabotage(String name, String table, String timing, String event, String condition) {}

    private static final List<Sabotage> STATEMENTS = List.of(
            new Sabotage("payment_request insert", "payment_request", "BEFORE", "INSERT", "1 = 1"),
            new Sabotage("payment insert", "payment", "BEFORE", "INSERT", "1 = 1"),
            new Sabotage("invoice pointer update", "invoice", "BEFORE", "UPDATE", "1 = 1"),
            new Sabotage("payment_event insert", "payment_event", "BEFORE", "INSERT", "1 = 1"),
            new Sabotage("COMMAND outbox insert", "outbox", "BEFORE", "INSERT", "NEW.destination = 'COMMAND'"),
            new Sabotage("STATUS outbox insert", "outbox", "BEFORE", "INSERT", "NEW.destination = 'STATUS'"),
            new Sabotage("audit insert", "audit_action", "BEFORE", "INSERT", "NEW.action = 'PAYMENT_ADMITTED'"));

    @Test
    void aFailureAtAnyStatementLeavesNoTraceAndTheKeyCanBeUsedAgain() {
        for (Sabotage s : STATEMENTS) {
            String key = key();
            rootJdbc.execute("CREATE TRIGGER t07_fail " + s.timing() + " " + s.event() + " ON " + s.table()
                    + " FOR EACH ROW BEGIN IF " + s.condition() + " THEN SIGNAL SQLSTATE '45000' "
                    + "SET MESSAGE_TEXT = 'forced failure'; END IF; END");
            try {
                assertThatThrownBy(() -> request(key)).as(s.name()).isInstanceOf(DataAccessException.class);
            } finally {
                rootJdbc.execute("DROP TRIGGER t07_fail");
            }

            assertThat(rowsWritten()).as("rows after failing %s", s.name()).isZero();
            assertThat(rootJdbc.queryForObject("SELECT active_payment_id FROM invoice WHERE id = ?", String.class, invoice))
                    .as("pointer after failing %s", s.name()).isNull();
            assertThat(rootJdbc.queryForObject("SELECT version FROM invoice WHERE id = ?", Long.class, invoice))
                    .as("invoice version after failing %s", s.name()).isZero();

            // the reservation was rolled back too, so the very same key now succeeds
            assertThat(request(key)).as("retry after %s", s.name()).isInstanceOf(Accepted.class);
            resetInvoice();
        }
    }

    /** Frees the invoice for the next sabotage round, child rows first; root bypasses the application on purpose. */
    private void resetInvoice() {
        rootJdbc.update("DELETE o FROM outbox o JOIN payment_event e ON e.event_id = o.event_id WHERE e.merchant_id = ?", merchant);
        rootJdbc.update("DELETE FROM payment_event WHERE merchant_id = ?", merchant);
        rootJdbc.update("UPDATE invoice SET active_payment_id = NULL, version = 0 WHERE id = ?", invoice);
        rootJdbc.update("DELETE FROM payment WHERE merchant_id = ?", merchant);
        rootJdbc.update("DELETE FROM payment_request WHERE merchant_id = ?", merchant);
        rootJdbc.update("DELETE FROM audit_action WHERE merchant_id = ? AND action = 'PAYMENT_ADMITTED'", merchant);
    }
}
```

```java
        var start = new CountDownLatch(1);

                    return request(key);
```

```java
/** Reads admission.capacity and admission.maintenance, cached for paybridge.admission.flag-cache-ms (default 1000). */
@Repository
public class MysqlSystemFlags implements SystemFlags {
    private record Snapshot(boolean maintenanceOn, boolean capacityClosed, long loadedAtMillis) {}

    private final JdbcTemplate jdbc;
    private final Clock clock;
    private final long cacheMillis;
    private volatile Snapshot snapshot;

    MysqlSystemFlags(JdbcTemplate jdbc, Clock clock, @Value("${paybridge.admission.flag-cache-ms:1000}") long cacheMillis) {
        this.jdbc = jdbc;
        this.clock = clock;
        this.cacheMillis = cacheMillis;
    }

    @Override
    public boolean maintenanceOn() {
        return current().maintenanceOn();
    }

    @Override
    public boolean capacityClosed() {
        return current().capacityClosed();
    }

    private Snapshot current() {
        Snapshot s = snapshot;
        long now = clock.millis();
        if (s != null && now - s.loadedAtMillis() < cacheMillis) {
            return s;
        }
        boolean[] values = new boolean[2];
        jdbc.query("SELECT flag_key, flag_value FROM system_flag WHERE flag_key IN ('admission.capacity', 'admission.maintenance')",
                rs -> {
                    if ("admission.maintenance".equals(rs.getString(1))) {
                        values[0] = "ON".equals(rs.getString(2));
                    } else {
                        values[1] = "CLOSED".equals(rs.getString(2));
                    }
                });
        snapshot = new Snapshot(values[0], values[1], now);
        return snapshot;
    }
}
```

```java
package com.paybridge.adapter.mysql;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.paybridge.application.port.AdmissionStore;
import com.paybridge.application.port.AuditStore;
import com.paybridge.contracts.PaymentEventEnvelope;
import com.paybridge.contracts.PaymentEventTypes;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.dao.PessimisticLockingFailureException;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.TransactionStatus;
import org.springframework.transaction.support.TransactionSynchronization;
import org.springframework.transaction.support.TransactionSynchronizationManager;
import org.springframework.transaction.support.TransactionTemplate;

/**
 * The DMR 6.1 admission transaction in plain SQL. The statement order IS the lock order (reservation, invoice,
 * payment, invoice pointer, event, outbox, audit), so it must not be reordered. JPA is deliberately not used here:
 * the order, the MySQL error numbers (1062, 1205, 1213) and the session lock wait timeout have to be visible.
 */
@Repository
public class MysqlAdmissionStore implements AdmissionStore {
    private static final Logger log = LoggerFactory.getLogger(MysqlAdmissionStore.class);
    private static final ObjectMapper JSON = new ObjectMapper();

    private final JdbcTemplate jdbc;
    private final TransactionTemplate tx;
    private final AuditStore audit;

    MysqlAdmissionStore(JdbcTemplate jdbc, PlatformTransactionManager transactionManager, AuditStore audit) {
        this.jdbc = jdbc;
        this.tx = new TransactionTemplate(transactionManager);
        this.audit = audit;
    }

    @Override
    public Optional<Replay> findReplay(String merchantId, String idempotencyKey) {
        List<Replay> rows = jdbc.query("SELECT r.payment_id, r.request_hash, p.status, p.aggregate_version "
                + "FROM payment_request r JOIN payment p ON p.id = r.payment_id "
                + "WHERE r.merchant_id = ? AND r.operation = 'REQUEST_PAYMENT' AND r.idempotency_key = ?",
                (rs, i) -> new Replay(rs.getString(1), rs.getString(2), rs.getString(3), rs.getLong(4)),
                merchantId, idempotencyKey);
        return rows.stream().findFirst();
    }

    @Override
    public Optional<MethodChoice> resolveMethod(String merchantId, String token) {
        List<MethodChoice> rows = jdbc.query("SELECT t.method_code FROM method_token t "
                + "JOIN method_catalog c ON c.method_code = t.method_code AND c.enabled = 1 "
                + "JOIN merchant_method m ON m.method_code = t.method_code AND m.merchant_id = ? AND m.enabled = 1 "
                + "WHERE t.token = ? AND t.enabled = 1", (rs, i) -> new MethodChoice(rs.getString(1)), merchantId, token);
        return rows.stream().findFirst();
    }

    @Override
    public AdmissionResult admit(AdmissionRequest request) {
        try {
            return tx.execute(status -> run(request, status));
        } catch (DuplicateKeyException e) {
            String message = String.valueOf(e.getMessage());
            if (message.contains("ux_payment_request")) {
                // We lost the key race: the winner has committed (or we would still be waiting). Read it in a new transaction.
                return findReplay(request.merchantId(), request.idempotencyKey())
                        .<AdmissionResult>map(AdmissionResult.Duplicate::new).orElseGet(AdmissionResult.Transient::new);
            }
            if (message.contains("ux_payment_one_active")) {
                log.error("ux_payment_one_active refused an admission the invoice pointer allowed; run the recovery checks");
                return new AdmissionResult.NotEligible();
            }
            throw e;
        } catch (PessimisticLockingFailureException e) {
            // 1205 lock wait timeout or 1213 deadlock: the transaction was rolled back, nothing was written.
            return new AdmissionResult.Transient();
        }
    }

    private AdmissionResult run(AdmissionRequest r, TransactionStatus status) {
        limitLockWait(r.lockWaitTimeoutSeconds());

        // 1. reservation
        jdbc.update("INSERT INTO payment_request (id, merchant_id, operation, idempotency_key, request_hash, payment_id, "
                + "requested_by, created_at) VALUES (?, ?, 'REQUEST_PAYMENT', ?, ?, ?, ?, UTC_TIMESTAMP(6))",
                UUID.randomUUID().toString(), r.merchantId(), r.idempotencyKey(), r.requestHash(), r.paymentId(), r.userId());

        // 2. invoice lock, then eligibility from the row just locked
        List<InvoiceRow> invoices = jdbc.query("SELECT amount_minor, currency, reference, active_payment_id FROM invoice "
                + "WHERE id = ? AND merchant_id = ? FOR UPDATE",
                (rs, i) -> new InvoiceRow(rs.getLong(1), rs.getString(2), rs.getString(3), rs.getString(4)),
                r.invoiceId(), r.merchantId());
        if (invoices.isEmpty()) {
            status.setRollbackOnly();
            return new AdmissionResult.InvoiceNotFound();
        }
        InvoiceRow invoice = invoices.get(0);
        if (invoice.activePaymentId() != null) {
            status.setRollbackOnly();
            return new AdmissionResult.NotEligible();
        }

        // 3. payment (amount and currency come from the invoice only)
        jdbc.update("INSERT INTO payment (id, merchant_id, invoice_id, method_code, method_token, amount_minor, currency, "
                + "status, aggregate_version, version, provider_key, scenario_run_id, correlation_id, requested_by, "
                + "created_at, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, 'REQUESTED', 1, 0, CONCAT('pbk-', ?), ?, ?, ?, "
                + "UTC_TIMESTAMP(6), UTC_TIMESTAMP(6))",
                r.paymentId(), r.merchantId(), r.invoiceId(), r.methodCode(), r.methodToken(), invoice.amountMinor(),
                invoice.currency(), r.paymentId(), r.scenarioRunId(), r.correlationId(), r.userId());

        // 4. invoice pointer
        int pointed = jdbc.update("UPDATE invoice SET active_payment_id = ?, version = version + 1 "
                + "WHERE id = ? AND active_payment_id IS NULL", r.paymentId(), r.invoiceId());
        if (pointed != 1) {
            throw new IllegalStateException("invoice pointer update changed " + pointed + " rows under the invoice lock");
        }

        // 5. STATE event, 6. two outbox rows
        jdbc.update("INSERT INTO payment_event (event_id, payment_id, merchant_id, event_class, event_type, schema_version, "
                + "aggregate_version, occurred_at, correlation_id, payload) "
                + "VALUES (?, ?, ?, 'STATE', ?, ?, 1, UTC_TIMESTAMP(6), ?, CAST(? AS JSON))",
                r.eventId(), r.paymentId(), r.merchantId(), PaymentEventTypes.PAYMENT_REQUESTED,
                PaymentEventEnvelope.CURRENT_SCHEMA_VERSION, r.correlationId(), requestedPayload(r, invoice));
        jdbc.update("INSERT INTO outbox (event_id, destination, exchange, routing_key, status, due_at, created_at) "
                + "VALUES (?, 'COMMAND', 'paybridge.commands', 'payment.collect.v1', 'PENDING', UTC_TIMESTAMP(6), UTC_TIMESTAMP(6))",
                r.eventId());
        jdbc.update("INSERT INTO outbox (event_id, destination, exchange, routing_key, status, due_at, created_at) "
                + "VALUES (?, 'STATUS', 'paybridge.events', 'payment.status.v1', 'PENDING', UTC_TIMESTAMP(6), UTC_TIMESTAMP(6))",
                r.eventId());

        // 7. audit, inside the same transaction (MysqlAuditStore requires one)
        audit.record(AuditStore.Entry.of(AuditStore.ActorType.USER, r.userId(), r.merchantId(), "PAYMENT_ADMITTED",
                "payment", r.paymentId(), AuditStore.Result.SUCCESS, r.correlationId()));
        return new AdmissionResult.Created(r.paymentId());
    }

    /** Shortens the lock wait for this transaction only and restores the pooled connection before it is returned. */
    private void limitLockWait(int seconds) {
        Integer previous = jdbc.queryForObject("SELECT @@SESSION.innodb_lock_wait_timeout", Integer.class);
        jdbc.execute("SET SESSION innodb_lock_wait_timeout = " + seconds);
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
            @Override
            public void beforeCompletion() {
                try {
                    jdbc.execute("SET SESSION innodb_lock_wait_timeout = " + previous);
                } catch (RuntimeException e) {
                    log.warn("could not restore innodb_lock_wait_timeout: {}", e.getClass().getSimpleName());
                }
            }
        });
    }

    private static String requestedPayload(AdmissionRequest r, InvoiceRow invoice) {
        Map<String, String> payload = new LinkedHashMap<>();
        payload.put("invoiceId", r.invoiceId());
        payload.put("invoiceReference", invoice.reference());
        payload.put("methodCode", r.methodCode());
        payload.put("amountMinor", Long.toString(invoice.amountMinor()));
        payload.put("currency", invoice.currency());
        payload.put("providerKey", "pbk-" + r.paymentId());
        try {
            return JSON.writeValueAsString(payload);
        } catch (JsonProcessingException e) {
            throw new IllegalStateException("event payload is not serializable", e);
        }
    }

    private record InvoiceRow(long amountMinor, String currency, String reference, String activePaymentId) {}
}
```

```java
package com.paybridge.core.graphql;

import com.netflix.graphql.dgs.DgsComponent;
import com.netflix.graphql.dgs.DgsMutation;
import com.netflix.graphql.dgs.DgsQuery;
import com.netflix.graphql.dgs.InputArgument;
import com.paybridge.application.payment.AdmissionActor;
import com.paybridge.application.payment.AdmitPayment;
import com.paybridge.application.payment.PaymentAdmission;
import com.paybridge.application.port.PaymentStore;
import com.paybridge.application.port.PaymentStore.PaymentRecord;
import com.paybridge.core.graphql.model.IdentityTypes.FieldProblem;
import com.paybridge.core.graphql.model.IdentityTypes.OperationProblem;
import com.paybridge.core.graphql.model.PaymentTypes.Payment;
import com.paybridge.core.graphql.model.PaymentTypes.PaymentAccepted;
import com.paybridge.core.graphql.model.PaymentTypes.RequestPaymentInput;
import com.paybridge.core.identity.ActorContext;
import graphql.schema.DataFetchingEnvironment;
import java.util.List;
import java.util.Map;

/**
 * requestPayment and payment(id). Authorization (OPERATOR / VIEWER in the signed merchant) has already happened in
 * {@link AuthorizationInstrumentation}. A payment of another merchant is reported exactly like a missing one.
 */
@DgsComponent
public class PaymentDataFetcher {
    private static final Map<PaymentAdmission.Code, String> MESSAGES = Map.of(
            PaymentAdmission.Code.VALIDATION_ERROR, "The request is not valid.",
            PaymentAdmission.Code.NOT_FOUND, "Invoice not found.",
            PaymentAdmission.Code.IDEMPOTENCY_CONFLICT, "This idempotency key was already used for a different request.",
            PaymentAdmission.Code.INVOICE_NOT_ELIGIBLE, "The invoice already has an active payment.",
            PaymentAdmission.Code.RATE_LIMITED, "Too many requests. Try again later.",
            PaymentAdmission.Code.TEMPORARILY_UNAVAILABLE,
            "Payments are temporarily unavailable. Retry with the same idempotency key.");

    private final AdmitPayment admitPayment;
    private final PaymentStore payments;

    public PaymentDataFetcher(AdmitPayment admitPayment, PaymentStore payments) {
        this.admitPayment = admitPayment;
        this.payments = payments;
    }

    @DgsMutation
    public Object requestPayment(@InputArgument RequestPaymentInput input, DataFetchingEnvironment env) {
        ActorContext actor = IdentityDataFetcher.granted(env).actor();
        PaymentAdmission result = admitPayment.admit(new AdmissionActor(actor.merchantId(), actor.userId(),
                actor.correlationId()), input.invoiceId(), input.methodToken(), input.idempotencyKey());
        if (result instanceof PaymentAdmission.Accepted accepted) {
            PaymentRecord record = payments.findById(accepted.paymentId())
                    .orElseThrow(() -> new IllegalStateException("admitted payment is not readable"));
            return new PaymentAccepted(toPayment(record), accepted.replayed());
        }
        PaymentAdmission.Rejected rejected = (PaymentAdmission.Rejected) result;
        List<FieldProblem> fields = rejected.fieldProblems() == null ? null
                : rejected.fieldProblems().stream().map(f -> new FieldProblem(f.field(), f.code(), f.message())).toList();
        return new OperationProblem(rejected.code().name(), MESSAGES.get(rejected.code()), rejected.retryAfterSeconds(),
                fields, null);
    }

    @DgsQuery
    public Payment payment(@InputArgument String id, DataFetchingEnvironment env) {
        String merchantId = IdentityDataFetcher.granted(env).actor().merchantId();
        return payments.findById(id).filter(p -> p.merchantId().equals(merchantId)).map(PaymentDataFetcher::toPayment)
                .orElse(null);
    }

    private static Payment toPayment(PaymentRecord p) {
        return new Payment(p.id(), p.merchantId(), p.invoiceId(), p.status(), Long.toString(p.amountMinor()), p.currency(),
                p.methodCode(), Long.toString(p.aggregateVersion()), p.providerReference(), p.createdAt(), p.updatedAt(),
                List.of(), null);
    }
}
```

```java
import graphql.analysis.MaxQueryDepthInstrumentation;
import graphql.schema.GraphQLTypeUtil;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

/** API contract 5.4: depth 8, complexity 300 (1 per field, plus 5 per page of 25 for list fields), document 8 KiB. */
public final class GraphQlLimits {
    public static final int MAX_DEPTH = 8;
    public static final int MAX_COMPLEXITY = 300;
    public static final int MAX_DOCUMENT_BYTES = 8 * 1024;
    private static final int DEFAULT_PAGE = 25;
    private static final int LIST_COST = 5;

    private GraphQlLimits() {}

    public static MaxQueryDepthInstrumentation depth() {
        return new MaxQueryDepthInstrumentation(MAX_DEPTH);
    }

    public static MaxQueryComplexityInstrumentation complexity() {
        return new MaxQueryComplexityInstrumentation(MAX_COMPLEXITY, (env, childComplexity) -> {
            int cost = 1;
            var type = GraphQLTypeUtil.unwrapNonNull(env.getFieldDefinition().getType());
            if (GraphQLTypeUtil.isList(type)) {
                Object limit = env.getArguments().get("limit");
                int size = limit instanceof Number n && n.intValue() > 0 ? n.intValue() : DEFAULT_PAGE;
                cost += LIST_COST * ((size + DEFAULT_PAGE - 1) / DEFAULT_PAGE);
            }
            return cost + childComplexity;
        });
    }

    @Configuration(proxyBeanMethods = false)
    static class Beans {
        @Bean
        MaxQueryDepthInstrumentation maxQueryDepth() {
            return depth();
        }

        @Bean
        MaxQueryComplexityInstrumentation maxQueryComplexity() {
            return complexity();
        }
    }
}
```

```java
package com.paybridge.core.graphql;

import java.nio.charset.StandardCharsets;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.graphql.server.WebGraphQlInterceptor;
import org.springframework.graphql.server.WebGraphQlRequest;
import org.springframework.graphql.server.WebGraphQlResponse;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ResponseStatusException;
import reactor.core.publisher.Mono;

/** Runs before everything else: an oversized document is refused (HTTP 413) before it is parsed or authenticated. */
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class DocumentSizeInterceptor implements WebGraphQlInterceptor {

    @Override
    public Mono<WebGraphQlResponse> intercept(WebGraphQlRequest request, Chain chain) {
        if (request.getDocument().getBytes(StandardCharsets.UTF_8).length > GraphQlLimits.MAX_DOCUMENT_BYTES) {
            return Mono.error(new ResponseStatusException(HttpStatus.PAYLOAD_TOO_LARGE, "Request too large"));
        }
        return chain.next(request);
    }
}
```

```java
package com.paybridge.application.port;

/** The DMR recovery check queries A to C: admission invariants that must hold after any restore or crash. */
public interface ConsistencyCheck {

    Report run();

    record Report(long pointersToMissingFailedOrForeign, long activePaymentsNotPointedTo, long reservationsWithoutPayment) {
        public boolean clean() {
            return pointersToMissingFailedOrForeign == 0 && activePaymentsNotPointedTo == 0 && reservationsWithoutPayment == 0;
        }
    }
}
```

```java
package com.paybridge.adapter.mysql;

import com.paybridge.application.port.ConsistencyCheck;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;

@Repository
public class MysqlConsistencyCheck implements ConsistencyCheck {
    private final JdbcTemplate jdbc;

    MysqlConsistencyCheck(JdbcTemplate jdbc) {
        this.jdbc = jdbc;
    }

    @Override
    public Report run() {
        return new Report(
                // A. pointer to a missing, FAILED or foreign payment
                count("SELECT COUNT(*) FROM invoice i LEFT JOIN payment p ON p.id = i.active_payment_id "
                        + "WHERE i.active_payment_id IS NOT NULL AND (p.id IS NULL OR p.status = 'FAILED' OR p.invoice_id <> i.id)"),
                // B. non-FAILED payment that its invoice does not point to
                count("SELECT COUNT(*) FROM payment p JOIN invoice i ON i.id = p.invoice_id "
                        + "WHERE p.status <> 'FAILED' AND (i.active_payment_id IS NULL OR i.active_payment_id <> p.id)"),
                // C. reservation without payment
                count("SELECT COUNT(*) FROM payment_request r LEFT JOIN payment p ON p.id = r.payment_id WHERE p.id IS NULL"));
    }

    private long count(String sql) {
        Long value = jdbc.queryForObject(sql, Long.class);
        return value == null ? 0 : value;
    }
}
```

```java
package com.paybridge.core.admission;

import com.paybridge.application.port.ConsistencyCheck;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.actuate.health.Health;
import org.springframework.boot.actuate.health.HealthIndicator;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;

/**
 * Runs the admission recovery checks once at startup. A violation makes readiness DOWN so a damaged database never takes
 * traffic. The log and the health details carry counts only, never ids.
 */
@Component("invoicePointersHealthIndicator")
public class InvoicePointersHealthIndicator implements HealthIndicator {
    private static final Logger log = LoggerFactory.getLogger(InvoicePointersHealthIndicator.class);

    private final ConsistencyCheck check;
    private volatile ConsistencyCheck.Report report;

    public InvoicePointersHealthIndicator(ConsistencyCheck check) {
        this.check = check;
    }

    @EventListener(ApplicationReadyEvent.class)
    public void runCheck() {
        report = check.run();
        if (!report.clean()) {
            log.error("admission consistency check failed: pointersToMissingFailedOrForeign={} activePaymentsNotPointedTo={} "
                    + "reservationsWithoutPayment={}", report.pointersToMissingFailedOrForeign(),
                    report.activePaymentsNotPointedTo(), report.reservationsWithoutPayment());
        }
    }

    @Override
    public Health health() {
        ConsistencyCheck.Report r = report;
        if (r == null) {
            return Health.unknown().withDetail("check", "pending").build();
        }
        var builder = r.clean() ? Health.up() : Health.down();
        return builder.withDetail("pointersToMissingFailedOrForeign", r.pointersToMissingFailedOrForeign())
                .withDetail("activePaymentsNotPointedTo", r.activePaymentsNotPointedTo())
                .withDetail("reservationsWithoutPayment", r.reservationsWithoutPayment()).build();
    }
}
```
